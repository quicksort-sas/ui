# Quicksort UI

React components in the Quicksort style, built on [shadcn/ui](https://ui.shadcn.com) and [Base UI](https://base-ui.com).
Ink, paper and stone carry the interface; lime marks the one thing that matters. Light and dark, accessible.

**Docs and live examples: [quicksort.design/components](https://quicksort.design/components)**

## Install

### shadcn registry (copy the source into your project)

```sh
pnpm dlx shadcn@latest add https://quicksort.design/r/theme.json      # once: tokens, fonts, dark mode
pnpm dlx shadcn@latest add https://quicksort.design/r/date-picker.json
```

Each component brings the components it depends on. You own the code from then on.

### npm (`@quicksort/ui`)

```sh
pnpm add @quicksort/ui
```

```css
/* your main CSS file */
@import "tailwindcss";
@import "@quicksort/ui/theme.css";
@source "../node_modules/@quicksort/ui/dist";
```

```tsx
import { Button, DatePicker } from "@quicksort/ui"

<Button variant="pivot">Book a call</Button>
<DatePicker placeholder="Workshop date" />
```

Needs React 19 and Tailwind CSS 4. Dark mode: add the class `dark` on `<html>`.

## Develop

```sh
pnpm install
pnpm dev                # docs at http://localhost:5173/components
pnpm build:lib          # npm package → dist/
pnpm build:site         # docs + registry → dist-docs/ (served by quicksort.design)
```

- Components: `src/components/ui` (shadcn, restyled) and `src/components/quicksort` (brand components).
- Theme: `src/styles/theme.css`. Design rules: [DESIGN.md](DESIGN.md).
- Docs examples: `src/examples/<slug>/*.tsx`, catalogued in `src/docs/catalog.ts`.
- The registry (`registry.json`) is generated by `scripts/registry.mjs`; don't edit it by hand.
